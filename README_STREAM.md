# MuSR-Stream (Unified Dynamic Belief)

MuSR-Stream extends MuSR with streaming evidence evaluation. Instead of one-shot QA, models update beliefs as evidence rounds are revealed.

This setup focuses on the murder mystery domain and supports a unified `dynamic_belief` track:
- `stream_only` cases: evidence updates only
- `counterfactual` cases: evidence updates plus one counterfactual correction block

## Setup

```bash
uv sync
```

## Dynamic Belief Dataset Format

Each line in `datasets_stream/murder_mystery_stream.jsonl` is one streamed case:

```json
{
  "case_id": "murder_mystery_0_q0",
  "domain": "murder_mystery",
  "question": "Who is the most likely murderer?",
  "suspects": ["Mackenzie", "Ana"],
  "gold_suspect": "Mackenzie",
  "gold_index": 0,
  "metadata": {
    "source_case_index": 0,
    "source_question_index": 0,
    "chunk_mode": "sentence",
    "n_rounds": 22,
    "story_hash_id": 12345
  },
  "rounds": [
    {"round_id": 1, "evidence_text": "..."},
    {"round_id": 2, "evidence_text": "..."}
  ]
}
```

Notes:
- Evidence is chunked only from the final narrative context.
- Tree reasoning artifacts are not exposed to the model in prompts.

For the CS422 dynamic benchmark, the recommended format is generated by:
`scripts/build_dynamic_belief.py` (default output track name: `dynamic_belief`).

Example dynamic belief instance:

```json
{
  "id": "dynamic_belief_12_q0",
  "track": "dynamic_belief",
  "question": "Who is the most likely murderer?",
  "suspects": ["A", "B"],
  "answer_index": 1,
  "answer_text": "B",
  "rounds": [
    {"round_id": 1, "evidence_text": "...", "evidence_type": "setup_sentence", "is_counterfactual": false},
    {"round_id": 2, "evidence_text": "...", "evidence_type": "tree_fact", "is_counterfactual": false},
    {"round_id": 9, "evidence_text": "...", "evidence_type": "counterfactual_update", "is_counterfactual": true}
  ],
  "metadata": {
    "update_type": "counterfactual",
    "has_counterfactual": true,
    "flip_required": true,
    "counterfactual_round_id": 9
  }
}
```

## 1) Convert Dataset to Stream Format

Sentence-by-sentence (default):

```bash
uv run python musr_stream/convert_murder_mystery_to_stream.py
```

Fixed chunking (`N=3` sentences per round):

```bash
uv run python musr_stream/convert_murder_mystery_to_stream.py --chunk-mode fixed --fixed-n 3
```

Useful options:
- `--input` (default: `datasets/murder_mystery.json`)
- `--output` (default: `datasets_stream/murder_mystery_stream.jsonl`)
- `--limit` to convert only first N source cases

## 1b) Build Unified Dynamic Belief Benchmark

Build `dynamic_belief` with a mix of stream-only and counterfactual cases:

```bash
uv run python scripts/build_dynamic_belief.py \
  --outdir benchmark_runs/cs422_v1/dynamic_belief \
  --seed 7 \
  --max-rounds 40 \
  --setup-sentences 2 \
  --counterfactual-rate 0.7 \
  --flip-rate 0.7
```

## 2) Run Streaming Eval

Set API key:

```bash
export TOGETHER_API_KEY="..."
```

Run eval (default limits to 1 case for smoke test):

```bash
uv run python -m eval_stream.eval_stream
```

Optional flags:
- `--input datasets_stream/murder_mystery_stream.jsonl`
- `--output outputs/musr_stream_eval.json`
- `--model ServiceNow-AI/Apriel-1.6-15b-Thinker`
- `--limit 10`
- `--temperature 0.0`
- `--max-tokens 512`

## 3) Metrics

- `final_accuracy`: final-round top suspect matches gold suspect
- `update_consistency`:
  - penalizes top-suspect flips across rounds
  - penalizes confidence decreases for the final predicted suspect
- `brier_final`: Brier score at final round
- `brier_mean`: mean Brier across rounds
- `flip_when_required` (counterfactual subset): whether model flips prediction after required correction
- `stability_when_not_required` (counterfactual subset): whether model avoids unnecessary flip
- `recovery_latency` (counterfactual subset): rounds needed to reach revised gold after correction point

The eval summary now also reports subset stats for:
- `counterfactual` cases
- `stream_only` cases

## Expected Output Files

- `datasets_stream/murder_mystery_stream.jsonl`: streamed dataset
- `outputs/musr_stream_eval.json`: eval config + aggregate summary + per-case round traces
- `benchmark_runs/cs422_v1/dynamic_belief/{train,dev,test}.jsonl`: unified dynamic belief benchmark
